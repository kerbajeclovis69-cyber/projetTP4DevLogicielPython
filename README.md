#
1. PRINCIPE DU JEU
#


Breakout (casse-briques) est un jeu dans lequel vous contrôlez une raquette horizontale située au bas de l'écran pour faire rebondir une balle. 



Le but est de détruire les briques situées en haut de l'écran en les frappant avec la balle, tout en l'empêchant de tomber sous la raquette.


#
2. RÈGLES DE VOTRE VERSION PYTHON
#



- Vies : Vous commencez la partie avec 2 vies. Si la balle passe sous la raquette, vous perdez 1 vie.

-Score : Chaque fois que la balle touche une brique, vous gagnez 1 point.

- Vitesse : La balle accélère au fil du temps, sa vitesse augmentant en fonction de votre score.


#
3. MODES DE DIFFICULTÉ
#



Le mode sélectionné modifie la résistance des briques :

- Mode Facile       : Briques avec 1 point de vie (détruites en 1 coup).

- Mode Intermédiaire: Briques avec 2 points de vie (détruites en 2 coups).

- Mode Difficile    : Briques avec 3 points de vie (détruites en 3 coups).


#
4. COMMANDES ET INTERFACE
#


- Bouton "Restart" : Permet de recommencer la partie à tout moment.

- Bouton "Quitter" : Permet de fermer le jeu.
